## Style Guide

### Color Palette
- **Neural (Blue)**: #1E90FF - Use for perception/neural network elements
- **Symbolic (Gold)**: #FFD700 - Use for reasoning/logic elements
- **Success (Green)**: #00FF00 - Use for checkmarks and validation
- **Background**: #1a1a1a - Dark theme throughout
- **Accents**: White (#FFFFFF) for text, subtle glows

### Typography
- **Titles**: Montserrat Bold (or similar modern sans-serif)
- **Body Text**: Inter Regular (clean, readable)
- **Code**: Fira Code (monospace with ligatures)
- **Sizes**: Large titles (48-60pt), body (24-32pt), code (20-24pt)

### Animation Style
- **Transitions**: Smooth fades (0.5s), no harsh cuts
- **Motion**: Ease in/out curves, nothing linear
- **Particles**: Use for data flow between layers
- **Glows**: Subtle bloom effects on highlights
- **Speed**: Professional pace, not too fast

### Audio
- **Music**: 
  - Intro/Outro: Upbeat electronic (120 BPM) - think tech product launch
  - Demo sections: Ambient tech background (80 BPM) - subtle, not distracting
  - Ensure: Royalty-free or properly licensed
- **Voiceover**: 
  - Professional, clear, enthusiastic but not overhyped
  - Pace: 150-160 words per minute
  - Full script provided in VIDEO_SCRIPT.md
